# Sineklik Sistemleri

Sineklik sistemleri için modern Next.js tabanlı web sitesi.

## Özellikler

- Next.js 15 + TypeScript + Tailwind CSS
- Responsive tasarım
- SEO optimizasyonu
- JSON-LD şemaları
- Mobil uyumlu arayüz

## Teknolojiler

- **Framework**: Next.js 15
- **Dil**: TypeScript
- **Stil**: Tailwind CSS
- **İkonlar**: Lucide React

## Geliştirme

```bash
npm install
npm run dev
```

## Üretim

```bash
npm run build
npm start
```
